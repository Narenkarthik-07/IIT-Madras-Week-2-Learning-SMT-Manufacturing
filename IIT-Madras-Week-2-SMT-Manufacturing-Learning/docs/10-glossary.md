# 10 — Glossary

| Term | Meaning |
|---|---|
| **SMT** | Surface Mount Technology: assembling components onto pads on a PCB surface. |
| **SMD** | Surface-mount device; an electronic component designed for surface mounting. |
| **PCB** | Printed Circuit Board; provides electrical interconnections and mechanical support. |
| **SPP** | Solder Paste Printing; transferring paste through stencil apertures onto PCB pads. |
| **SPI** | Solder Paste Inspection; checking printed solder paste deposits. |
| **AOI** | Automated Optical Inspection; image-based inspection of visible PCB assembly features. |
| **Stencil** | Patterned sheet with apertures used to deposit solder paste onto selected pads. |
| **Solder paste** | Mixture of solder-alloy particles and flux used to form solder joints during reflow. |
| **Squeegee** | Blade or tool that moves paste across a stencil to fill apertures. |
| **Feeder** | Mechanism that presents components to a pick-and-place machine. |
| **Pick-and-place** | Automated process that picks components from supply packaging and positions them on the PCB. |
| **Fiducial marker** | Recognisable reference feature used by a machine to determine board position or orientation. |
| **Reflow profile** | Temperature-versus-time behaviour experienced by an assembly during reflow soldering. |
| **Solder joint** | Electrical and mechanical connection formed by solder between intended surfaces. |
| **Tombstoning** | Defect in which a small component, commonly a two-terminal chip part, stands on end during soldering. |
| **Solder bridging** | Unintended solder connection between neighbouring pads, leads, or conductors. |
| **BOM** | Bill of Materials; list of parts required for an assembly, usually with quantities and identifiers. |
| **DFM** | Design for Manufacturability; designing a product so it can be manufactured consistently and efficiently. |
| **Yield** | Proportion of produced units that meet defined acceptance criteria at a specified process point. |
| **SMT line throughput** | Rate at which the line processes boards or assemblies over time. |
| **Time above liquidus (TAL)** | Time during which the measured assembly temperature is above the solder alloy's liquidus temperature. |
| **Stencil aperture** | Opening in a stencil through which solder paste is transferred. |
| **False positive** | An inspection system flags a condition as a defect when it is acceptable. |
| **False negative** | An inspection system fails to flag a real defect. |
| **Fiducial registration** | Use of reference marks to align a PCB coordinate system with machine coordinates. |
| **Reflow oven** | Equipment that applies a controlled thermal process to solder a populated PCB. |
